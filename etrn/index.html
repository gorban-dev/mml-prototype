ММЛ · подписание титулов (ЭТрН)

  1. Маршрутный лист → оранжевая плашка → «Подписание ЭТрН».
  2. Титул 2: галочка → «ПОДПИСАТЬ». Через ~5 с приходит «Подписан», плашки исчезают, у заданий появляются кнопки «QR-КОД».
  3. «ЗАДАНИЯ · N» — список заданий титула.
  4. Титул 4 текущего МЛ: первая попытка нарочно с ошибкой → «ПОВТОРИТЬ».
  5. МЛ от 05.11 (Госключ): «СФОРМИРОВАТЬ» → «ПЕРЕЙТИ В ГОСКЛЮЧ».
  6. Меню → «Задания на сегодня» → карточка → QR, листать «‹ ПРЕДЫДУЩЕЕ / СЛЕДУЮЩЕЕ ›».
